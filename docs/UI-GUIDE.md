# 界面与模块分工

各模块统一使用蓝灰色日夜主题、轻边框卡片和一致的表单控件。主按钮突出当前任务，项目库与编辑界面分层呈现。中英文、手动保存、自动保存与原有项目格式继续适用。

| 页面             | 主要任务                                     | 后续入口                   |
| ---------------- | -------------------------------------------- | -------------------------- |
| 小说首页         | 查看最近作品、全书架写作进度，记录跨作品灵感 | 点击具体作品继续写作       |
| 作品书架         | 搜索、排序、新建、导入与删除作品             | 打开该作品的写作台         |
| 小说写作台       | 编辑本书章节，管理本书资料，使用 AI 辅助工具 | 创作旅程、世界观、返回书架 |
| OC 项目主页      | 概览角色、创作清单和人物档案                 | 编辑档案、世界观           |
| TRPG 项目主页    | 概览冒险、备团清单与副本库                   | 备团编辑、局域网房间       |
| 酒馆项目主页     | 概览角色卡、开场白、场景与世界书             | 制作与收藏、局域网、扩展   |
| 自由模式与世界观 | 管理条目、关系、地图、百科等资料视图         | 各创作模式、导出与备份     |
| 局域网与扩展     | 管理房间或配置已安装服务                     | 延续各模式原有流程         |

## 小说布局

书架不提供拆书、智能体或作者记忆入口，避免在未打开作品时误选工具作用范围。首页的便笺属于跨作品灵感；写作台的资源、结构卡片、作者记忆和自定义面板属于当前作品，两者用途及保存位置不同。

写作台左侧按「创作 / 本书资料 / AI 辅助」分组。正文页保留目录、正文和本章资料，顶部可收起资料；专注模式只保留正文与顶部操作。小窗口将资料放在正文下方，进一步缩窄时目录也改为纵向排列。关闭资料或切换专注不会删除输入。

## 样式维护

`src/theme.css` 定义日夜主题变量，`src/workspace-ui.css` 统一跨模块表面色、控件、间距与响应式布局；后者在入口最后引入。功能模块保留各自布局和业务状态。新增页面优先复用 `--ui-bg`、`--ui-panel`、`--ui-input`、`--ui-text`、`--ui-muted`、`--ui-line` 和 `--ui-accent`，避免写死仅适合夜间的颜色。

验证命令：`npm run build`、`npm run lint`、`npm test`、`npm run test:novel-desk`、`npm run test:mode-homes`。桌面回归使用隔离数据目录和模拟服务；不会使用真实模型密钥。

## 主题状态维护

组件自身使用主题变量，世界观各视图的 Tailwind 类使用 `bg-ui-panel`、`text-ui-text`、`hover:bg-ui-hover` 等语义颜色。避免仅在外层覆盖旧的深色类，也不要用类名子串选择器匹配颜色：这会把 `hover:` 类误当作普通状态，并漏掉弹窗。

普通控件悬停使用 `--ui-hover`；主按钮使用 `--ui-accent-hover` 与 `--ui-on-accent`。图片遮罩、用户定义的标签色和关系类型色保留各自含义。图谱提示框、输入框、原生下拉框、候选面板和灵感便笺都随日夜主题更新。

`npm run test:theme` 在隔离的 Electron 测试窗口中切换日夜主题、触发实际鼠标悬停，并检查页面背景与主按钮文字颜色；覆盖世界观视图、小说、各模式工作台、局域网以及模板、AI 设置、插件和更新弹窗，截图写入 `test-results/theme-*.png`。
