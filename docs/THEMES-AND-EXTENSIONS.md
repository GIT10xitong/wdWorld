# 主题、主页与模式扩展（1.10.0）

工具栏提供白天／夜晚切换，默认白天，选择在本机记住。小说首页、书架、写作台、创作旅程、工具和弹窗使用统一配色。点击左上角 WD WORLD 保存当前草稿并返回本模式主页；项目中的局域网房间会结束。切换创作模式仍在原生菜单「文件」中。

OC、TRPG、酒馆、自由模式世界观、局域网和插件页面也使用相同的蓝灰主题。各模块以内容和操作区分用途，减少装饰性大背景。世界观正文页仅展示已设置的封面，默认占位图保留在浏览卡片中，避免挤占正文编辑空间。布局与功能分工见[界面指南](UI-GUIDE.md)。

外层「插件中心」只显示完整酒馆、TRPG 模式包。进入小说、OC、自由、酒馆或 TRPG 后，在该模式「插件扩展」中下载和管理适用的小插件。导入文件与下载地址也检查分类，不能在外层误装小插件。

进入项目后点击「插件扩展」（酒馆为「酒馆扩展」），再点击「管理与下载扩展 → 获取官方插件目录」。安装时检查来源和权限；模式项目库上的「插件扩展」可直接打开对应分类的管理页。

扩展包可声明 `targets` 数组，值为 `free`、`novel`、`oc`、`trpg`、`tavern`。未声明的旧扩展按酒馆处理；酒馆和 TRPG 扩展须声明对应模式包依赖。图片、语音和外部服务适配器可面向多个模式；当前本地记忆扩展只支持酒馆。现有官方小插件以酒馆为主，其他模式的目录可能为空，可导入声明相应目标模式的标准包。

插件仍采用 WDWorld v1 声明式 JSON 与 HTTP 服务适配，不执行外部任意 JavaScript，不直接兼容依赖 SillyTavern 页面或后端的脚本。配置与密钥继续在桌面本机加密保存，安装前显示来源和权限。
