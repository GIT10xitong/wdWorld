# WD World 1.10.2 版本说明

日期：2026-10-18。状态：源码更新，未发布 1.10.2 安装包。此版本承接 1.10.1 的稳定性改进，重点解决资料查找、导航分散、文件控件翻译和世界书编辑区显示不全的问题。

## 主要变化

- **世界书更容易查找**：左侧目录支持标题、触发词与正文搜索，以及启用、停用、常驻筛选；右侧一次编辑一条。筛选不会缩减导出内容，修改后不再匹配搜索的当前条目仍保留在编辑区。
- **世界书操作完整可达**：桌面双栏中表单可滚动，底部保留启用、常驻、排序与删除；窄窗口或较矮窗口改为上下排列并允许完整滚动，修复正文和按钮被裁切。
- **工作台按任务分区**：酒馆按角色草稿、世界书、角色卡工坊、场景卡与 AI 助手切换；TRPG 按备团草稿、副本库与 AI 助手切换；OC 分为人物档案与 AI 助手。收藏卡片和副本库增加搜索。
- **常用按钮集中**：创作主页、编辑工作台、保存本页和 AI 设置进入插件中心所在顶栏。英文或小窗口中导航自动换行；同一会话内跨模块返回恢复编辑分区及世界书选中条目。
- **文件选择跟随语言**：小说资料、插件、酒馆和 TRPG 导入统一显示可翻译的选择按钮、空文件提示与所选文件名，支持键盘操作和重复选择同一文件。系统弹出的文件窗口仍由操作系统决定语言。

小说书架与写作台的分工、各模块统一的日夜主题及悬停颜色修复继续保留。完整界面规则见[界面与模块分工](UI-GUIDE.md)，模式入口见[创作主页说明](MODE-HOMES.md)。

## 如何使用新版

源码分支为 `release/1.10.2`。已有本地修改时先提交或另行保存，再更新代码：

```sh
git fetch origin
git switch release/1.10.2
git pull --ff-only
npm ci
npm run desktop
```

Windows PowerShell 可将 `npm` 写为 `npm.cmd`。源码与依赖齐全时，双击 `start-desktop.cmd` 也会构建并启动当前代码；缺少源码运行条件时，脚本依次尝试 1.10.2、1.10.1 的本地便携目录。回退到旧包时不会包含新版界面。

本轮未更改项目文件格式或数据存储位置，无需手动迁移作品。更新前仍可通过应用导出完整项目备份；已有 1.10.1 安装包不会随 Git 源码更新。需要分发安装包时，按[候选验收流程](RELEASE-CANDIDATE.md)重新构建和验收；正式应用内更新还需完成[发布流程](UPDATES.md)。

## 验证范围

本轮界面修复已通过构建、Lint、133 项单元／集成测试，以及模式主页、小说写作台、插件、自动叙事和主题桌面回归。世界书目录回归包含 120 条测试条目、筛选中编辑、新建与删除、跨模块返回定位。

新增 `npm run test:ui-layout`，验证中英文界面、键盘文件选择、重复导入，以及 1440×900、1100×720、900×650、760×650 窗口中的导航与世界书可访问性。该测试独立于现有九组 `test:desktop:all`，应单独执行。

桌面回归使用隔离测试数据和模拟服务。本轮没有重新执行 1.10.2 安装包的安装、升级或在线更新验收；之前的 1.10.1 候选包验收不能替代新版二进制验收。
