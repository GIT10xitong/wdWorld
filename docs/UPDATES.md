# GitHub 应用更新（1.10）

更新源固定为公共仓库 `actrox/wdWorld` 的稳定 GitHub Releases。入口是「帮助 → 检查应用更新」或右下角「应用更新」。打包版本启动时默认检查更新，可以关闭；开发源码不会自动联网检查。

- **NSIS 安装版**：检查版本 → 下载并校验 → 保存并重启安装。不在普通退出时自动安装，不降级，不使用预发行版。
- **源码／便携版**：可以检查版本和打开发布页，不覆盖当前目录。首次迁移需安装 NSIS 版。
- 安装前刷新草稿和项目保存；保存失败或仍有局域网房间时停止安装。AI 任务需先完成或停止。
- 继续使用 `%APPDATA%/wdworld` 的数据位置，卸载器不删除作者数据。定期导出备份仍有必要。

## 发布流程

```sh
npm ci
npm run build
npx electron-builder --win nsis --publish never
```

产物位于 `release/installer/`：安装 EXE、`.blockmap`、`latest.yml`。构建嵌入指向 `actrox/wdWorld` 的 `app-update.yml`。更新器校验文件摘要；当前无代码签名证书，摘要不等同于独立数字签名。

更新版本号并完成检查后，创建对应版本的草稿 Release，上传上述三种文件，核对版本、大小、文件名和 SHA-512，最后公开发布。不要只上传源码或 ZIP，不要替换已公开版本的二进制。随后从较早的已安装版本测试更新。

1.10.0 当前为本地构建，本轮未上传或发布 GitHub Release。若公开版本比当前版本旧，即使缺少更新清单也不会提示降级；若存在更高版本但缺少清单，则提示检查失败。发布带上述文件的新版本后，更新源才具备完整分发内容。源码／便携版仍可读取公开 Release 的版本信息。

测试覆盖版本比较、重复下载、安装前保存阻断、界面和构建配置。没有替换用户正式安装或伪造一次跨版本升级验收。
