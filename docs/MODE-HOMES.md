# OC、TRPG 与酒馆主页

这三个模式现在包含「本模式项目库 → 创作主页 → 编辑工作台」。项目库读取全部本地项目，按模式过滤，支持搜索、创建、打开备份与确认删除。返回项目库前刷新保存并结束当前局域网房间；切换其他模式仍使用菜单中的「切换创作模式」。TRPG 和酒馆仍需要先安装对应模式插件。

最新源码将「创作主页」「编辑工作台」「保存本页」「AI 设置」统一放到插件中心所在顶栏；编辑区通过分区导航切换。酒馆世界书采用左侧搜索目录、右侧单条编辑，角色卡、场景卡与 TRPG 副本库支持搜索。跨模块返回恢复当前会话的编辑位置，详见[编辑布局说明](UI-GUIDE.md#酒馆trpg-与-oc-编辑布局)。

## OC 角色创作室

主页展示当前角色概念与动机、档案填写清单、人物库和世界关系数量。点击人物打开对应世界观条目。档案字段保留手动填写和 AI 候选流程，确认新建或采纳后加入世界观。归档人物不计入主页，AI 待确认条目保留标记；关系数量统计当前非归档世界条目之间的关系。

## TRPG 主持人准备台

主页汇总本次冒险、规则系统、备团清单、收藏副本、插件提供的预设、地点与待确认设定。首页仅预览玩家可见背景，不展示主持人秘密和实际跑团记录全文。完整资料在「编辑工作台」查看。

「选择或导入副本」与副本库入口定位到原有副本编辑区，载入前仍需预览确认。支持副本／世界 JSON、TXT 和 Markdown。局域网入口只切换到房间管理页，不自动创建房间或公开内容。

## 酒馆制作台

主页展示当前角色卡、开场白预览、制作清单、角色与场景收藏、世界书数量及启用状态。主页入口可定位角色卡工坊、场景卡管理和世界书编辑区；收藏条目入口打开相应管理区，不自动覆盖当前草稿。原有导入导出与确认载入流程保持可用。

局域网房间与酒馆扩展均可从主页进入。扩展服务仍需安装相应插件并配置，主页不会自动调用模型、发起语音／图像请求或联网开房。

## 保存与统计

主页从当前文档和世界观条目派生统计，不创建示例数据或虚构活动记录。填写清单只表示字段非空，不表示设定质量或跑团准备已经审查通过。返回主页保留编辑中的草稿，编辑状态每 10 秒自动保存，页头提供「保存本页」。正常离开项目与关闭应用会刷新保存队列；已有加密存储和备份格式保持兼容。

界面支持简体中文与英文、白天与夜晚主题。顶部 WD WORLD 保存并返回本模式项目库，结束运行中的房间；主页内部「创作主页」返回当前项目概览，不退出项目。小插件在本模式的扩展入口下载，完整模式包在外层插件中心安装。小说首页与自由模式原有入口保留。
