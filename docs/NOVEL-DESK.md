# 小说首页、书架与写作台（1.10.0）

选择小说模式进入创作首页，默认浅蓝灰色，可切换夜晚主题。左侧仅保留首页、作品书架、灵感便笺以及创建和导入操作；主区显示最近两本作品、今日码字进度、灵感速记、最近 14 天记录和作品字数排行。点击「全部作品」进入完整书架，可搜索、排序、创建作品或导入完整项目 JSON。桌面书架读取全部本地小说，不受最近项目 20 条限制。旧自由模式项目仍在自由模式中，不自动改变类型。

首页与书架负责跨作品管理，不再提供单本作品工具或「当前作品」选择器。点击作品进入写作台，所有资料和 AI 工具明确作用于已打开的作品；新建作品同样进入写作台。

## 进度与灵感

字数按正文纯文本非空白字符统计。排行显示当前正文总量；每日进度记录本版使用期间每次正文变更的正向字数差，区分手动新增和采纳 AI 后的新增。粘贴计手动，删除不扣减，同长度修订不计新增；未采纳候选、设定、版本恢复不计入。旧作品不会补造历史。每日目标可修改，14 天记录汇总书架中的小说，记录随作品备份。

灵感速记的草稿每 10 秒自动保存，点击「记下来」立即存入便笺库；打开作品、切换模式或正常关闭前会刷新保存。便笺库最多 200 条，每条 5000 字符，支持查看、删除与明文 JSON 导出。桌面版草稿、便笺和日目标统一加密保存在用户数据目录的 `novel-home.wdw`，不包含在单本作品备份中。浏览器预览使用本机 localStorage，不具备桌面加密保护。无法解密时阻止覆盖，保存失败保留编辑内容并阻止离开。

## 写作台

打开作品默认进入写作台。左侧是章节目录，中间是正文编辑器，右侧填写本章大纲、事实摘要、引用设定与写作要求。支持卷名、草稿／完成状态、章节字数目标与专注模式。可以直接手写，也可以切换「创作旅程」按原有七阶段逐步完成。

工作区导航分为「创作」（写作台、结构化板块）、「本书资料」（资源库、世界观联动、作者记忆、自定义面板）和「AI 辅助」（智能体、文风修订、拆书、设定体检）。顶部「本章资料」可收起或恢复资料栏，内容保留；「专注」仅在正文页显示。窄窗口把资料放到正文下方，专注时仍隐藏导航、目录和资料，扩大正文宽度。

续写和摘要沿用模型设置、长上下文分段与作者确认机制。过期候选不会覆盖后续修改。手动版本和采纳前版本可在创作旅程的版本历史中恢复。每 10 秒自动保存；手动保存、切换页面、返回书架或正常关闭也会刷新保存队列。桌面项目继续加密保存。

## 创作工具

| 板块       | 功能与边界                                                                                                                                                   |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 结构化板块 | 情节、伏笔、人物弧光卡片，自定义分类／状态；当前没有拖拽关系图。                                                                                             |
| 资源库     | 手动素材或 UTF-8 TXT / Markdown 导入，单文件最多 1 MB、每本书最多 100 条资源。                                                                               |
| 作者记忆   | 本书的文风、视角、用词和作者要求，加入后续写作上下文；不跨书共享，不替代正式故事事实。故事想法与人物初建阶段仍仅使用对应阶段资料。                           |
| 自定义面板 | 标题、分类、正文组成的笔记面板；不执行脚本，尚不支持任意布局组件。                                                                                           |
| 去 AI 味   | 生成文风修订候选，作者确认后替换原章节并保留版本；不提供 AI 检测分数或规避保证。                                                                             |
| 拆书       | 选择资源分析结构、冲突、节奏、视角、伏笔；只发送该资源和本次要求，不发送作者记忆或其他作品资料。不声称读过未提供的全书。                                     |
| 智能体系统 | 默认策划、写作、审校，可编辑、增删、启用、上移和单独运行。工作流顺序调用同一配置模型，每步引用上一步候选；最多 12 个角色，每步产生模型用量，不自动写入正文。 |
| 设定体检   | 本地检测重名与空内容；AI 检查已确认设定、章节摘要和当前正文，要求引用出处，不自动修改正式设定。                                                              |

最近 30 条 AI 工具结果随作品保存，可以存入资源库。资源、卡片、作者记忆、面板、智能体和结果均随完整项目 JSON 导出／导入；导出为明文，不包含 API 密钥。图片、PDF、EPUB、Word 拆书尚未支持。

智能体结果可点击「追加到关联章节（保留快照）」采纳；若生成后章节已变化，会拒绝过期候选。运行工作流本身不会自动改写正文。

首页、书架、写作台、创作旅程和工具面板统一使用蓝灰色界面，支持白天／夜晚切换并记住选择。中英文均可切换，统计与入口连接实际作品数据。点击左上角 WD WORLD 保存并返回本模式主页。

## 与本书世界观联动

写作台「世界观联动」列出故事想法、大纲、文风、章节正文与摘要、结构卡片、资源、作者记忆、自定义面板、智能体配置和工具结果。选择资料、核对标题与条目类型，再确认同步；默认作为资料笔记。每本书只关联自己的世界观，完整项目备份会保留关联。

AI 工具结果自动加入本书世界观，标记为「AI 待确认」笔记；作者确认同步后转为正式条目。智能体结果可由作者确认追加到关联章节，追加前保留版本，正文已变化时拒绝过期候选。资料笔记不会自动当作世界事实加入后续工具提示词，人物与规则应核对后选择相应类型。

同一资料重复同步更新原条目，不产生副本。资料后续编辑需要再次确认同步；若世界观条目已被人工修改、归档或删除，会阻止覆盖。可解除关联后重新建立条目，原有条目保留。这里是确认式同步，不是双向自动覆盖。
